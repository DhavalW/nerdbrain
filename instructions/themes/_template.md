# <Theme name>

Capture format for a design theme — a reusable visual position, especially one refined in
a shipped app. Copy, fill in, add an inventory line in `../index.md`. Under ~80 lines.

A theme is a *position with a system attached* (`../design.md`): enough constraint that
two apps built on it feel related, enough freedom that they aren't clones. Concrete hex
values and font names are starting points to tune per app, not law.

---

## Position

One sentence: what this should feel like, and to whom. Everything below serves it.

## The one idea

The single organizing move that carries the design. One thing, committed to everywhere.

## Systems

- **Type:** families (with fallbacks), scale ratio, the sizes that jump
- **Space:** base unit, the multiples in play
- **Color:** accent strategy, neutral temperature, dark-mode stance
- **Surfaces:** radius, borders, shadow philosophy — one coherent set
- **Motion:** durations, easing, what animates and what never does
